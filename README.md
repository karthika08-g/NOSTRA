# NOSTRA
## Nostra – Fashion E-commerce Website

Nostra is a modern, responsive fashion e-commerce website developed using HTML, CSS, and JavaScript. It features an elegant design, product collections, interactive navigation, and a mobile-friendly slide-out menu. Users can browse and search products, filter collections, add items to their cart, and manage their wishlist. The website provides a smooth and user-friendly shopping experience across desktop, tablet, and mobile devices.

**Technologies Used:** HTML, CSS, JavaScript

**Key Features:**
- Responsive design for all devices
- Interactive product carousels
- Product search and filtering
- Add-to-cart functionality
- Wishlist management
- Mobile slide-out navigation
- Modern and elegant user interface
